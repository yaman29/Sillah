# جنّة صِلة — برنامج أسوة

📋 **[`CLAUDE.md`](./CLAUDE.md) هو ملف المواصفات الكامل — اقرأه قبل أي تعديل.**

`SillaParadise.jsx` — مكوّن React واحد: الطالب يسجّل سننه اليومية،
وكل سنّة تبني شيئًا في جنّته تنمو حتى تكتمل في ٣٠ يومًا.

## الشاشات الثلاث

| التبويب | ما فيه |
|---|---|
| **جنّة صِلة** | المشهد: تجوّل في الأرض، سلايدر الأيام، معاينة اليوم ٣٠ |
| **التعبئة** | تقويم الشهر، شبكة ٣×٣ لكل قسم، سنن سريعة |
| **تحرير السنن** | تعديل الأقسام والسنن وأحاديثها |

## تحرير السنن

كل تعديل يُطبَّق فورًا ويُحفظ في `localStorage` تحت `silla.sunan.v1`،
فتراه في بقيّة الشاشات في اللحظة نفسها.

- **الأقسام**: أضِف · سمِّ · لوِّن · رتِّب · احذف (سننه تنتقل للمجاور، لا تضيع)
- **السنّة**: اسحبها بإصبعك بين الأقسام، أو اضغطها لتحرير الاسم، الحديث،
  القسم، طريقة التسجيل (نعم/لا أو عدّاد)، الجواهر، وسم السنن السريعة،
  الأيقونة، وما تبنيه في الجنّة
- **تصدير**: يعطيك كتلة `DEFAULT_SECS` جاهزة تُلصق في الملف نفسه
  لتصير هي الأصل الذي يبدأ منه كل مستخدم جديد
- **استعادة الأصل**: يمسح تعديلات هذا المتصفّح ويرجع للسنن الـ٢٦

## الاستعمال

```jsx
import SillaParadise from "./SillaParadise.jsx";

<SillaParadise theme="light" initialLog={{}} />        // بالتبويبات الثلاثة
<SillaParadise theme="light" editable={false} />       // بإخفاء تبويب التحرير
```

ولوحة التحرير وحدها في صفحة مستقلّة:

```jsx
import { SillaAdmin } from "./SillaParadise.jsx";
```

## ملاحظات للتطوير

- `SUNAN` و`ITEMS` و`TOTAL` ارتباطات حيّة (`export let`) لا ثوابت — كل تعديل يمرّ
  بـ `setSunan()`، وكل مكوّن يقرأها يستدعي `useSunanVersion()` أولًا. التفصيل في §١٤.
- `i` في كل سنّة = البناء في المشهد (مفتاح في `DRAW` و`SPOT`)،
  و`ic` = أيقونة الواجهة — تغييرها لا يمسّ ما يُبنى.
- كل رسّام في `DRAW` يأخذ `(x, y, n)` و`n` = عدد الأيام (سقف ٣٠).
  اختبره عند `n = 0` و`n = 30` قبل التسليم.
